# Frozen country comparison panel

Version 1 freezes the country groups before generating the blog's comparative
results. Country membership must not change in response to observed Brazilian
performance. Any later change requires a new version and a written rationale.

| Group | Countries |
| --- | --- |
| Focus | Brazil |
| AI frontier | United States, China |
| Latin America | Argentina, Chile, Colombia, Mexico |
| Structural peers | India, Indonesia, South Africa, Turkey |
| Emerging AI investment reference | United Arab Emirates |
| Developed references | Canada, United Kingdom, France, Germany |

The machine-readable source is `country-comparison-panel.csv`.
